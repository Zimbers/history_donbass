ветка main это готовая сборка мода ее никогда не менять без проверок и соглосования
ветка backup основная для работы туда кидать версии мода измененые в backup кидать только полностью папками а не отдельные файлы
ветка hotfixies для изменений и исправления ошибок из backup только точечные и конкретные 
ветка versions нужна для архивации и документации если какая-то версия сломается можно оперативно будет взять отсюда
